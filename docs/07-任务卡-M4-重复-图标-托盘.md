## M4-1 任务重复

**前置**：无
**目标**：任务可按 每天/每周/每月/每年 重复，勾选完成即结算当期并自动滚到下一期（滚动式）。

### 给 agent 的任务描述（直接粘贴）

```
实现任务重复。先读：
- D:\ztodo\docs\01-产品方案框架-v1.md 第 4.4 节（重复语义——严格照此实现）、第 6 节（repeat 字段 + completions 表）

实现：
1. 新增迁移 src-tauri/migrations/002_repeat_completions.sql（对齐 001 的写法，禁止改历史迁移）：
   - ALTER TABLE tasks ADD COLUMN repeat TEXT NOT NULL DEFAULT 'none';
   - CREATE TABLE completions(
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       task_id INTEGER NOT NULL,
       title TEXT NOT NULL,           -- 标题快照，任务后续改名不影响历史
       done_at TEXT NOT NULL);
   - 回填存量：INSERT INTO completions(task_id, title, done_at)
     SELECT id, title, done_at FROM tasks WHERE done = 1 AND done_at IS NOT NULL;
2. Task 结构体与所有查询补 repeat 字段；add_task / update_task 接受 repeat，
   枚举校验（none|daily|weekly|monthly|yearly，非法回 none）。
3. toggle_task 完成路径（0→1）改造：
   - 所有任务完成都写一条 completions 记录（title 快照 + 当前 UTC done_at）；
   - 重复任务：不置 done，改为滚动——remind_at 从当前期按周期向前推进，
     直到落到第一个未来时刻（过期多日只补一期，中间跳过不堆积）：
     daily +1 天 / weekly +7 天 / monthly 用 chrono Months::new(1)（月末钳位，如 1-31→2-28）/
     yearly 用 Years::new(1)（2-29→2-28）；钟点保持不变，全程 UTC；
     notified 复位 0；
   - 非重复任务：维持现有行为（done=1 + done_at）。
   - 撤销路径（1→0）：现有清理之外，删除该任务最近一条 completions 记录（保对账一致）。
4. clear_reminder：清提醒同时把 repeat 重置 'none'（无提醒时间的任务不允许重复）。
   update_task 改时间：repeat 保留不动（锚点自然变为新时间）。
5. 前端 ReminderPicker（提醒设置弹层）：时间行下方新增「重复」行，五档
   不重复/每天/每周/每月/每年，默认不重复；任务尚未设置提醒时间时隐藏该行；
   随弹层确定一起保存，取消不保存（与时间行为一致）。
6. TaskItem：任务有重复时在时间旁显示循环标记 ↻（icons.tsx 加小图标）。
7. 周报 ReportView 数据源切换：从 tasks(done=1) 改为按周查 completions
   （后端查询一并改/新增命令）；展示与复制格式完全不变（MM-DD 标题 / 「本周完成：」+「· 标题」）；
   存量数据靠回填，翻历史周不丢。
8. 确认 Toast 的 [完成] 按钮走 toggle_task 同一路径（是则滚动自动生效，不用改 toast.rs）。
9. 自测：每天重复勾掉→时间滚到明天同时刻、任务留在清单；过期 3 天的每日任务勾掉→
   直接滚到明天（只补一期）；每月 1-31 勾掉→下期 2-28；清提醒→重复回不重复；
   周报同时能看到回填的旧记录与新结算记录。
10. cargo check + 前端 tsc 无错误后提交："M4-1: 任务重复"。
```

### 验收（你来操作）

- [ ] 给任务设"每天 9:00 + 每天"：勾选完成后任务不消失，时间自动变明天 9:00，↻ 标记在
- [ ] 上面这条进周报，本周能看到这一笔完成记录
- [ ] 故意不做一个每日重复任务过一天：它挂"过期"区且不再弹通知；勾掉后直接滚到明天
- [ ] 没设提醒时间的任务，弹层里看不到"重复"行
- [ ] 设了重复的任务清除提醒后，重复变回"不重复"
- [ ] 升级前的历史已完成任务在周报里还能翻到（回填生效）
- [ ] Toast 点 [完成]，重复任务同样滚动

## M4-2 应用图标重制（Figma AI 生成 → 全套替换）

**前置**：无（提示词部分立即可用；替换部分等图标定稿）
**目标**：Win11 Fluent 风新图标（白色对勾 + 渐变圆角方形），替换 exe / 任务栏 / 安装包全套图标。

### 给你的操作指引（Figma AI）

用下面**主提示词**，把结尾的配色句分别换成三个变体，各生成几版对比（同配色多生成几次挑最顺眼的）：

**主提示词（英文，直接粘贴到 Figma AI）：**

```
A modern Windows 11 style app icon for a minimalist to-do list app. A rounded-square
tile with a smooth diagonal gradient background and a subtle soft inner glow,
featuring a single bold white checkmark as the central glyph. Flat vector style,
clean geometry, generous padding around the checkmark, calm and minimal.
No text, no letters, no numbers, no outline, no drop shadow, no 3D, no photorealism,
single glyph only. Centered composition, must stay recognizable at small sizes.
Gradient: deep blue #2563EB flowing to cyan #06B6D4.
Square 1024x1024 canvas, the rounded-square tile fills the entire canvas.
```

**三个配色变体**（只换 "Gradient:" 那一句）：

1. 蓝青（默认）：`Gradient: deep blue #2563EB flowing to cyan #06B6D4.`
2. 绿青：`Gradient: emerald green #10B981 flowing to teal #14B8A6.`
3. 紫蓝：`Gradient: violet #7C3AED flowing to bright blue #3B82F6.`

**托盘单色备用版**（仅当彩色图标缩到托盘尺寸发糊看不清时才用）：

```
A monochrome pure white checkmark icon with rounded stroke ends, geometric and
minimal, on a fully transparent background. No tile, no text, single glyph,
designed for the Windows system tray at small sizes. 32x32.
```

**导出要求**：定稿后导出 **1024×1024 PNG，不透明实底**（圆角方形铺满画布，不要透明边缘），保存为 `D:\ztodo\design\icon\icon-1024.png`，然后交给 agent 执行下面部分。

### 给 agent 的任务描述（直接粘贴）

## M4-3 系统托盘

**前置**：建议 M4-2 完成（用新图标）；不阻塞，可先用现图标开发
**目标**：托盘常驻图标，左键切换面板，右键菜单 = 展开/收起面板 + 打开设置 + 退出。

### 给 agent 的任务描述（直接粘贴）

```
实现系统托盘。先读：
- D:\ztodo\docs\01-产品方案框架-v1.md 第 3.5 节（托盘规格——严格照此实现）

实现：
1. src-tauri/Cargo.toml：tauri 依赖 features 增加 "tray-icon"
   （Tauri 2 官方内置能力，开启 feature 即可，不新增任何第三方 crate；用户已知情同意）。
   菜单用 tauri 内置 menu 模块。
2. lib.rs 的 setup 建托盘（可拆独立 tray.rs 模块，非 Win32 调用不受 window_ctl/toast 门控限制）：
   TrayIconBuilder，图标用应用默认图标，tooltip「TodoEdge」。
3. 左键单击（TrayIconEvent 左键抬起）= 切换面板，按当前运行模式分流：
   - 贴边模式：复用 window_ctl.rs 既有展开/收起路径（与点细条等效，含同样的动画与状态维护，
     不另写一套几何代码）；
   - 窗口模式（1.2.0 已有双模式）：主窗口 show()/hide() 切换。
   当前模式判断沿用现有 settings/状态逻辑。
4. 右键菜单三项（全中文，文案风格与设置页一致）：
   - 「展开/收起面板」：与左键同路径；
   - 「打开设置」：贴边模式先展开面板、再 emit 事件让前端打开设置弹层；窗口模式直接 emit；
   - 「退出」：与设置页 exit_app 同路径（app.exit(0)）；设置页退出按钮保留不动。
5. 自测：贴边/窗口两种模式下左键都能正确切换；菜单三项行为正确；
   面板展开/收起动画不受影响；提醒 Toast 各按钮不受影响；
   Win11 深色/浅色任务栏下托盘图标均可见。
6. cargo check + 前端 tsc 无错误后提交："M4-3: 系统托盘"。
```
