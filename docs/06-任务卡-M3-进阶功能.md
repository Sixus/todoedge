### 给 agent 的任务描述（直接粘贴）


## M3-5 Fences 式 pin 桌面（WorkerW，最高风险，可砍）

**前置**：M3-1 \~ M3-4 完成
**目标**：把面板钉在壁纸层（壁纸之上、桌面图标之下，Win+D 不消失）。

### 给 agent 的任务描述（直接粘贴）

```
实现 pin 到桌面。先读：
- D:\ztodo\docs\01-产品方案框架-v1.md 第 3.1③/3.4 节（WorkerW 路线）
- 参考实现思路：FindWindow("Progman") → SendMessageTimeout(0x052C) 生成 WorkerW
  → EnumWindows 找到位于 SHELLDLL_DefView 之后的 WorkerW → SetParent(主窗口,
  workerW)。开源参考：3939LiveWallpaper（C#）、Lively Wallpaper。

实现：
1. window_ctl.rs 新增 pin_to_desktop() / unpin_from_desktop()：
   #[cfg(windows)]，全部 Win32 调用留在此文件（AGENTS.md 平台纪律）。
2. pin 模式语义：面板以展开态常驻桌面（细条收起逻辑停用），位置固定右缘
   （可先用垂直居中+M3-4 偏移），不抢焦点属性保持。
3. 入口：底栏或设置里加「钉到桌面」开关；再次点击取消 pin 恢复贴边模式。
4. 兼容性自测清单（逐一验证并记录）：
   - Win+D 后面板仍在
   - 桌面图标可正常点击（面板不挡图标区）
   - 分辨率/DPI 变化后位置是否错乱
   - 资源管理器重启（explorer 崩溃重启）后 WorkerW 失效需重新挂载——监听
     TaskbarCreated 消息重挂
5. 已知风险：与 Tauri 窗口库（tao）可能有消息循环/DPI 坑，若 3 轮修不好，
   如实汇报卡点，我们评估砍掉此功能（贴边模式已覆盖 90% 需求）。
6. cargo check 通过后提交："M3-5: pin 桌面"。
```

### 验收（你来操作）

- [ ] 开启「钉到桌面」：面板常驻桌面右缘
- [ ] 按 Win+D 显示桌面，面板还在；桌面图标仍能正常双击
- [x] 关闭开关恢复普通贴边模式，一切如常
- [x] 重启电脑后 pin 状态不要求保持（当前会话有效即可）
