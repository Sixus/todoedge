# TodoEdge 更新日志

TodoEdge 是一款 Windows 桌面待办小工具：平时收成屏幕右缘的一条半透明细线，鼠标靠近即滑出清单；到点的任务通过 Windows 原生通知提醒，可以直接在通知里完成或选择稍后提醒。所有数据保存在本地电脑。

以下按版本倒序列出每次发布的主要内容。

## V1.4.0（2026-09-09）

**新增**

- **透明度随心调**：设置里新增「面板透明度」滑杆，60%~95% 随意调节，数字越大面板越实。贴边模式的透明面板、窗口模式的普通透明背景、还有收起的细条，都跟着这根滑杆一起变，调完立即生效并自动记住。

**改进**

- **收回更利落**：「收回延时」最低可以从 0.5 秒调到 0.1 秒，鼠标一移开面板就迅速收起，喜欢灵敏手感的可以调得更快了。

**升级提示**

- 从旧版本升级：任务与设置全部保留。窗口模式选「普通透明」的朋友会发现面板比以前略实一点（默认统一为 70%），在设置里拖动滑杆即可调回喜欢的浓度。

## V1.3.0（2026-09-08）

**新增**

- **任务重复**：任务可以设为每天 / 每周 / 每月重复。完成后它会自动排到下一个重复日期（比如每天 9 点的提醒，做完一次就自动变成明天 9 点），不用再手动新建。隔了几天没顾上做也没关系，只会顺延到最近的下一次，不会攒出一堆过期提醒。
- **系统托盘**：任务栏托盘区常驻应用图标，左键单击即可显示 / 隐藏面板；右键菜单可以展开面板、打开设置或退出应用。
- **全新应用图标**：换上了更清爽的渐变对勾新图标。

**改进**

- **周报更完整**：完成过的任务现在有独立的完成记录，往回翻周报不会丢；在周报里删除某条记录，也不会影响任务本身。
- **设置重复更顺手**：在提醒设置里选定时间后，可以直接选重复周期，一步到位。

**升级提示**

- 从旧版本升级：原有的任务、提醒和完成历史全部保留，无需任何操作。
- 如果安装后桌面图标没有变化，是 Windows 的图标缓存没刷新，刷新桌面或重启一次电脑即可。

## V1.2.0（2026-09-04）

**新增**

- **两种运行模式**：默认的屏幕贴边模式之外，新增自由窗口模式——面板变成一个普通桌面小窗，可以拖动位置、自由调整大小。
- **窗口背景模糊**：窗口模式下背景支持系统级实时模糊（类似手机控制中心的毛玻璃效果），也可切换回普通透明；深浅色、不同显卡环境下都稳定清晰。
- **隐私锁**：一键锁定面板，锁屏后内容全部隐藏、点击才能解锁；开启「失焦自动上锁」后，离开面板达到设定时长会自动上锁，防止旁人窥屏。
- **窗口置顶**：一键让面板悬浮在所有窗口最前面，随时可见。

## V1.1.0（2026-09-03）

**新增**

- **「今日已完成」分组**：勾掉的任务收进清单底部的分组，点开可查看，也能直接改回来。
- **撤销保护**：完成任务或删除任务后，底部会弹出提示条，15 秒内可一键撤销；连续操作多条也能各自撤销。
- **过渡动画**：面板滑出、勾选完成、弹层弹出等全套动画，可在设置里一键开关。

## V1.0.0（2026-09-03）

TodoEdge 首个正式版发布。

**新增**

- **贴边常驻**：屏幕右缘一条半透明细线，鼠标靠近即滑出待办面板，移开自动收回。
- **任务管理**：添加、编辑、删除、勾选完成，支持拖拽调整顺序；过期的任务自动置顶标红。
- **提醒通知**：到点弹出 Windows 原生通知，通知里可直接完成任务、选择稍后提醒；支持中文输入自动识别时间（如「明天9点开会」）。
- **周报**：按周回顾完成过的任务，可向前翻看，一键复制纯文本。
- **全局热键**：无论在做什么，快捷键随时呼出 / 收起面板。
- **外观**：深浅色跟随系统；透明面板与实体面板一键切换。
- **开机自启**：可选开启，开机即静默待命。
